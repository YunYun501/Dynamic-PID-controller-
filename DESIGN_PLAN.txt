OVERVIEW
========
Build a Gymnasium-based simulation for a pendulum system with:
1. Multiple control modes (position, velocity, acceleration)
2. PID controller implementation
3. Future-ready for RL-based PID parameter tuning
4. Easy parameter configuration
5. Comprehensive data logging
6. Pygame visualization (T-shaped joint geometry)


CORE REQUIREMENTS
=================

1. PHYSICS ENGINE
   - Accurate pendulum dynamics with gravity, damping, friction
   - Semi-implicit Euler integration (stable and fast)
   - Support for variable timesteps
   - Handle torque limits and angle constraints

2. CONTROL MODES
   - Position Control: Target angle → PID → Torque
   - Velocity Control: Target angular velocity → Controller → Torque
   - Acceleration Control: Target angular acceleration → Controller → Torque

3. PID CONTROLLER
   - Configurable gains (Kp, Ki, Kd)
   - Anti-windup for integral term
   - Derivative filtering (optional)
   - Easy to swap/extend for RL agents

4. CONFIGURATION SYSTEM
   - Single source of truth for all parameters
   - Easy to create different experiment configs
   - Support for config inheritance/presets
   - Validation of parameter ranges

5. LOGGING SYSTEM
   - High-frequency data capture (every timestep)
   - Efficient storage (numpy arrays → CSV/HDF5)
   - Metadata tracking (config, timestamps, git hash)
   - Automatic plot generation

6. RL INTEGRATION POINTS
   - PID gains as part of observation space (optional)
   - Reward function for tracking performance
   - Episode-based parameter updates
   - Meta-learning capability

2. PHYSICS ENGINE (core/physics.py)
------------------------------------

Key Classes:
- PendulumDynamics: Forward dynamics (torque → acceleration)
- PendulumKinematics: Forward kinematics (angle → position)
- Integrator: Numerical integration schemes

```python
class PendulumDynamics:
    """Compute pendulum dynamics"""
    
    def __init__(self, config: PhysicsConfig):
        self.config = config
    
    def compute_acceleration(
        self, 
        angle: float, 
        velocity: float, 
        torque: float
    ) -> float:
        """
        Compute angular acceleration from current state and applied torque.
        
        Equation of motion:
        I * α = τ_applied + τ_gravity + τ_damping + τ_friction
        
        Returns:
            Angular acceleration (rad/s²)
        """
        # Gravitational torque
        tau_gravity = -self.config.arm_mass * self.config.gravity * \
                      (self.config.arm_length / 2) * np.sin(angle)
        
        # Damping torque (proportional to velocity)
        tau_damping = -self.config.damping_coefficient * velocity
        
        # Friction torque (Coulomb friction)
        tau_friction = -self.config.friction_coefficient * np.sign(velocity)
        
        # Total torque
        tau_total = torque + tau_gravity + tau_damping + tau_friction
        
        # Angular acceleration
        alpha = tau_total / self.config.moment_of_inertia
        
        return alpha
    
    def integrate_step(
        self,
        angle: float,
        velocity: float,
        torque: float,
        dt: float
    ) -> Tuple[float, float, float]:
        """
        Integrate one timestep using semi-implicit Euler.
        
        Returns:
            (new_angle, new_velocity, acceleration)
        """
        # Compute acceleration at current state
        acceleration = self.compute_acceleration(angle, velocity, torque)
        
        # Semi-implicit Euler integration
        new_velocity = velocity + acceleration * dt
        new_angle = angle + new_velocity * dt
        
        # Apply constraints
        new_angle = np.clip(new_angle, -self.config.max_angle, 
                           self.config.max_angle)
        new_velocity = np.clip(new_velocity, -self.config.max_velocity,
                              self.config.max_velocity)
        
        return new_angle, new_velocity, acceleration


class PendulumKinematics:
    """Compute forward kinematics"""
    
    def __init__(self, arm_length: float):
        self.arm_length = arm_length
    
    def get_end_effector_position(self, angle: float) -> Tuple[float, float]:
        """
        Get (x, y) position of pendulum end.
        
        Convention: angle=0 is vertical down, positive=clockwise
        """
        x = self.arm_length * np.sin(angle)
        y = self.arm_length * np.cos(angle)
        return x, y
```

class ControllerBase(ABC):
    """Abstract base class for all controllers"""
    
    @abstractmethod
    def compute_control(
        self, 
        target: float, 
        current: float, 
        dt: float
    ) -> float:
        """Compute control signal"""
        pass
    
    @abstractmethod
    def reset(self):
        """Reset controller state"""
        pass


class PIDController(ControllerBase):
    """Standard PID controller with anti-windup"""
    
    def __init__(self, config: PIDConfig):
        self.config = config
        self.reset()
    
    def reset(self):
        """Reset internal state"""
        self.integral = 0.0
        self.prev_error = 0.0
        self.prev_derivative = 0.0
    
    def compute_control(
        self, 
        target: float, 
        current: float, 
        dt: float
    ) -> float:
        """
        Compute PID control signal.
        
        Args:
            target: Desired setpoint
            current: Current measured value
            dt: Time since last update
        
        Returns:
            Control signal (torque)
        """
        # Error
        error = target - current
        
        # Proportional term
        p_term = self.config.kp * error
        
        # Integral term with anti-windup
        self.integral += error * dt
        self.integral = np.clip(
            self.integral, 
            -self.config.integral_limit, 
            self.config.integral_limit
        )
        i_term = self.config.ki * self.integral
        
        # Derivative term with filtering
        derivative = (error - self.prev_error) / dt if dt > 0 else 0.0
        
        if self.config.derivative_filter_tau > 0:
            # Low-pass filter on derivative
            alpha = dt / (self.config.derivative_filter_tau + dt)
            derivative = alpha * derivative + (1 - alpha) * self.prev_derivative
            self.prev_derivative = derivative
        
        d_term = self.config.kd * derivative
        
        # Update state
        self.prev_error = error
        
        # Total control
        control = p_term + i_term + d_term
        
        return control
    
    def get_state(self) -> Dict[str, float]:
        """Get internal state for logging"""
        return {
            "integral": self.integral,
            "prev_error": self.prev_error,
            "prev_derivative": self.prev_derivative
        }
    
    def set_gains(self, kp: float, ki: float, kd: float):
        """Update PID gains (for RL adaptation)"""
        self.config.kp = kp
        self.config.ki = ki
        self.config.kd = kd

class PendulumEnv(gym.Env):
    """
    Gymnasium environment for pendulum control.
    
    Observation Space:
        - angle (rad)
        - angular_velocity (rad/s)
        - target_angle (rad) [if available]
        - error (rad)
        - PID gains (optional, for meta-learning)
    
    Action Space (depends on control_mode):
        - position: target angle (rad)
        - velocity: target angular velocity (rad/s)
        - acceleration: target angular acceleration (rad/s²)
    
    Reward:
        - Negative tracking error + efficiency penalty
    """
    
    metadata = {"render_modes": ["human", "rgb_array"], "render_fps": 50}
    
    def __init__(self, config: ExperimentConfig):
        super().__init__()
        
        self.config = config
        
        # Initialize components
        self.dynamics = PendulumDynamics(config.physics)
        self.kinematics = PendulumKinematics(config.physics.arm_length)
        self.controller = PIDController(config.pid)
        
        # Initialize renderer
        if config.render.render_mode is not None:
            from environment.renderer import PendulumRenderer
            self.renderer = PendulumRenderer(config.render)
        else:
            self.renderer = None
        
        # Define action/observation spaces
        self._setup_spaces()
        
        # State variables
        self.angle = 0.0
        self.velocity = 0.0
        self.acceleration = 0.0
        self.torque = 0.0
        self.step_count = 0
        self.target = 0.0
    
    def _setup_spaces(self):
        """Define action and observation spaces"""
        # Action space depends on control mode
        if self.config.simulation.control_mode == "position":
            self.action_space = spaces.Box(
                low=-self.config.physics.max_angle,
                high=self.config.physics.max_angle,
                shape=(1,),
                dtype=np.float32
            )
        # ... similar for velocity, acceleration
        
        # Observation space
        obs_low = np.array([
            -self.config.physics.max_angle,      # angle
            -self.config.physics.max_velocity,   # velocity
            -self.config.physics.max_angle,      # target
            -2 * self.config.physics.max_angle,  # error
        ], dtype=np.float32)
        
        obs_high = np.array([
            self.config.physics.max_angle,
            self.config.physics.max_velocity,
            self.config.physics.max_angle,
            2 * self.config.physics.max_angle,
        ], dtype=np.float32)
        
        self.observation_space = spaces.Box(
            low=obs_low, high=obs_high, dtype=np.float32
        )
    
    def reset(self, seed=None, options=None):
        """Reset environment to initial state"""
        super().reset(seed=seed)
        
        if self.config.simulation.random_initial_state:
            self.angle = self.np_random.uniform(
                -self.config.physics.max_angle,
                self.config.physics.max_angle
            )
            self.velocity = self.np_random.uniform(-0.5, 0.5)
        else:
            self.angle = self.config.simulation.initial_angle
            self.velocity = self.config.simulation.initial_velocity
        
        self.acceleration = 0.0
        self.torque = 0.0
        self.step_count = 0
        self.target = 0.0
        
        self.controller.reset()
        
        obs = self._get_observation()
        info = self._get_info()
        
        return obs, info
    
    def step(self, action):
        """Execute one timestep"""
        # Extract target from action
        self.target = float(action[0])
        
        # Compute control signal using PID
        if self.config.simulation.control_mode == "position":
            self.torque = self.controller.compute_control(
                self.target,
                self.angle,
                self.config.simulation.dt
            )
        # ... similar for velocity, acceleration modes
        
        # Clip torque to limits
        self.torque = np.clip(
            self.torque,
            -self.config.physics.max_torque,
            self.config.physics.max_torque
        )
        
        # Integrate physics
        self.angle, self.velocity, self.acceleration = \
            self.dynamics.integrate_step(
                self.angle,
                self.velocity,
                self.torque,
                self.config.simulation.dt
            )
        
        self.step_count += 1
        
        # Compute reward
        reward = self._compute_reward()
        
        # Check termination
        terminated = False  # Pendulum can't really fail
        truncated = self.step_count >= self.config.simulation.max_steps
        
        obs = self._get_observation()
        info = self._get_info()
        
        return obs, reward, terminated, truncated, info
    
    def _get_observation(self):
        """Get current observation"""
        return np.array([
            self.angle,
            self.velocity,
            self.target,
            self.target - self.angle  # error
        ], dtype=np.float32)
    
    def _get_info(self):
        """Get auxiliary information"""
        return {
            "angle": self.angle,
            "velocity": self.velocity,
            "acceleration": self.acceleration,
            "torque": self.torque,
            "target": self.target,
            "error": self.target - self.angle,
            "step": self.step_count,
            "pid_state": self.controller.get_state()
        }
    
    def _compute_reward(self):
        """Compute reward for RL training"""
        # Tracking error penalty
        error = abs(self.target - self.angle)
        tracking_reward = -error
        
        # Energy efficiency penalty
        energy_penalty = -0.01 * (self.torque ** 2)
        
        # Velocity penalty (prefer smooth motion)
        velocity_penalty = -0.001 * (self.velocity ** 2)
        
        total_reward = tracking_reward + energy_penalty + velocity_penalty
        
        return total_reward
    
    def render(self):
        """Render current state"""
        if self.renderer is not None:
            return self.renderer.render(self)
    
    def close(self):
        """Clean up resources"""
        if self.renderer is not None:
            self.renderer.close()
```

class DataLogger:
    """Efficient data logging for experiments"""
    
    def __init__(self, config: LoggingConfig, experiment_name: str):
        self.config = config
        self.experiment_name = experiment_name
        
        # Create output directories
        self.data_dir = Path(config.output_dir) / "data"
        self.data_dir.mkdir(parents=True, exist_ok=True)
        
        # Storage (numpy arrays for efficiency)
        self.data = {
            "time": [],
            "angle": [],
            "velocity": [],
            "acceleration": [],
            "torque": [],
            "target": [],
            "error": [],
            "reward": [],
            "pid_integral": [],
            "pid_derivative": []
        }
        
        self.metadata = {}
    
    def log_step(self, info: Dict, reward: float):
        """Log data from one timestep"""
        self.data["time"].append(info["step"] * self.config.simulation.dt)
        self.data["angle"].append(info["angle"])
        self.data["velocity"].append(info["velocity"])
        self.data["acceleration"].append(info["acceleration"])
        self.data["torque"].append(info["torque"])
        self.data["target"].append(info["target"])
        self.data["error"].append(info["error"])
        self.data["reward"].append(reward)
        self.data["pid_integral"].append(info["pid_state"]["integral"])
        self.data["pid_derivative"].append(info["pid_state"]["prev_derivative"])
    
    def save(self, episode: int, config: ExperimentConfig):
        """Save logged data to disk"""
        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        base_name = f"{self.experiment_name}_ep{episode:03d}_{timestamp}"
        
        # Convert to numpy arrays
        data_arrays = {k: np.array(v) for k, v in self.data.items()}
        
        # Save as CSV
        csv_path = self.data_dir / f"{base_name}.csv"
        df = pd.DataFrame(data_arrays)
        df.to_csv(csv_path, index=False)
        
        # Save metadata as JSON
        metadata = {
            "experiment_name": self.experiment_name,
            "episode": episode,
            "timestamp": timestamp,
            "config": config.to_dict(),
            "num_steps": len(self.data["time"]),
            "final_error": float(self.data["error"][-1]),
            "mean_error": float(np.mean(np.abs(data_arrays["error"]))),
            "max_torque": float(np.max(np.abs(data_arrays["torque"])))
        }
        
        json_path = self.data_dir / f"{base_name}_metadata.json"
        with open(json_path, "w") as f:
            json.dump(metadata, f, indent=2)
        
        return csv_path, json_path
    
    def reset(self):
        """Clear logged data for next episode"""
        for key in self.data:
            self.data[key].clear()
```

```python
def run_pid_experiment(config: ExperimentConfig, num_episodes: int = 1):
    """Run PID control experiment"""
    
    # Create environment
    env = PendulumEnv(config)
    
    # Create logger
    logger = DataLogger(config.logging, config.name)
    
    for episode in range(num_episodes):
        obs, info = env.reset()
        logger.reset()
        
        episode_reward = 0.0
        
        for step in range(config.simulation.max_steps):
            # Generate target trajectory (sinusoidal, step, etc.)
            target = generate_target(step, config)
            action = np.array([target])
            
            # Step environment
            obs, reward, terminated, truncated, info = env.step(action)
            
            # Log data
            logger.log_step(info, reward)
            episode_reward += reward
            
            # Render
            if config.render.render_mode == "human":
                env.render()
            
            if terminated or truncated:
                break
        
        # Save episode data
        csv_path, json_path = logger.save(episode, config)
        print(f"Episode {episode}: Total Reward = {episode_reward:.2f}")
        
        # Generate plots
        if config.logging.auto_plot:
            plot_path = Visualizer.plot_episode(
                csv_path, 
                Path(config.logging.output_dir) / "plots"
            )
            print(f"  Saved plot: {plot_path}")
    
    env.close()


def generate_target(step: int, config: ExperimentConfig) -> float:
    """Generate target trajectory"""
    t = step * config.simulation.dt
    
    # Example: Sinusoidal trajectory
    amplitude = 0.5  # radians
    frequency = 0.5  # Hz
    target = amplitude * np.sin(2 * np.pi * frequency * t)
    
    return target
```

KEY DESIGN DECISIONS
====================

1. Why Dataclasses for Config?
   - Type safety
   - Easy validation
   - Serializable to JSON/YAML
   - IDE auto-completion

2. Why Separate Physics from Environment?
   - Easier to test physics independently
   - Can reuse physics in other projects
   - Clean separation of concerns

3. Why Abstract Controller Base?
   - Easy to add new controllers (MPC, LQR, etc.)
   - Consistent interface for environment
   - Future-proof for RL agents

4. Why Numpy Arrays for Logging?
   - Memory efficient (vs lists of dicts)
   - Fast vectorized operations
   - Easy conversion to pandas/CSV

5. Why Gymnasium (not custom)?
   - Standard RL interface
   - Compatible with stable-baselines3, RLlib
   - Well-documented and tested
   - Large community


RL INTEGRATION STRATEGY
=======================

Current: Fixed PID gains
→ Meta-learning: RL adjusts gains based on performance
→ Full RL: Replace PID entirely with learned policy

Meta-Learning Approach:
- Observation: [angle, velocity, error, integral, derivative, kp, ki, kd]
- Action: [Δkp, Δki, Δkd] (small adjustments)
- Reward: Tracking performance over episode
- Update frequency: Every N steps or per episode

Challenges:
- Credit assignment (which gain to adjust?)
- Stability during exploration
- Transfer to different trajectories

Solutions:
- Use curriculum learning (easy → hard trajectories)
- Constrain gain adjustments (clipping)
- Multi-task training (varied targets)
